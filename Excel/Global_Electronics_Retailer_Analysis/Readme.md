# Global Electronics Sales Analysis 

## Project Overview

This project is an end-to-end Excel data analysis project focused on analyzing the sales performance of a global electronics supplier.

The project combines multiple datasets containing information about customers, products, stores, exchange rates, and sales transactions. 
The raw data was cleaned and transformed using Power Query, after which the datasets were combined to create a consolidated Master_Sales dataset.

The final analysis was presented through an interactive Excel dashboard using PivotTables, PivotCharts, KPI cards, and slicers.

## Project Objectives

The main objective of this project was to analyze overall business performance and answer questions such as:

- How much total revenue and profit did the business generate?

- How has revenue and profit changed over the years?

- Which product categories generate the highest revenue?

- Which products are the top revenue contributors?

- Which customer countries generate the most revenue?

- Which stores perform best?

- How does revenue change on a monthly basis?

- How do sales results change based on year, category, country, and brand?

## Data Preparation

The project involved multiple datasets related to customers, products, sales, stores, and other supporting information.

The data preparation process included:

- Importing the datasets into Excel using Power Query.

- Checking and correcting data types.

- Removing duplicate records and unnecessary inconsistencies.

- Cleaning text fields where required.

- Merging related datasets using common keys.

- Creating a consolidated Master_Sales table.

- Creating additional fields to support analysis, including:

      Order Year
      Year-Month
      Revenue
      Profit-related metrics

The final Master_Sales dataset was used as the primary source for PivotTables and dashboard visualizations.

## Key Business Insights

- 2019 was the strongest-performing year, with total revenue reaching approximately ₹18 Cr.
- The Computers category was the largest revenue contributor, generating around ₹19 Cr.
- The United States was the leading customer market, contributing approximately ₹30 Cr in revenue.
- WWI Desktop PC2.33 X2330 Black was the highest-revenue product, generating approximately ₹505L.
- Store 44 was the top-performing store, generating around ₹11 Cr in revenue.
- The business showed strong growth from 2016 to 2019, followed by a noticeable decline in the later period.
- The results highlight an opportunity to further investigate the factors behind the post-2019 decline in sales performance.
