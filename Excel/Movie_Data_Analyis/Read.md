# 🎬 Movie Data Analysis & Insights Dashboard
## 📌 Project Overview

This project analyzes a movie dataset using Microsoft Excel to identify trends and insights related to movie ratings, popularity, genres, languages,
audience votes, and release years.

The project covers the complete data analysis workflow, including data exploration, data cleaning, 
feature engineering, analysis, PivotTables, and interactive dashboard creation.

## 🎯 Objectives
- Analyze the distribution of movie ratings.
- Identify the most popular movies.
- Explore movie release trends over the years.
- Analyze movie genres and languages.
- Understand audience engagement through vote counts.
- Compare popularity across different rating categories.
- Build an interactive and visually appealing Excel dashboard.

## 📂 Dataset

The dataset contains movie-level information such as:

- Release Date
- Movie Title
- Overview
- Popularity
- Vote Count
- Vote Average
- Original Language
- Genre
- Poster URL

After cleaning, the final dataset contains 9,817 movie records.

## 🧹 Data Cleaning & Feature Engineering

The following steps were performed:

- Checked for missing values.
- Removed 10 incomplete records containing missing numerical values.
- Checked for duplicate records.
- Verified date and numerical data types.
- Converted release dates into proper Excel date format.
- Created a Release Year column.
- Created a Rating Category column.
- Rating Categories
- Rating Range	Category
  
[
< 4	Low

4 to < 6	Average

6 to < 8	Good

## 🔍 Key Insights

- **Good-rated** movies represent the **largest rating** category in the dataset.
- The dataset contains **9,817** movies after cleaning.
- The overall **average movie rating** is **6.44**.
- The overall **average popularity score** is **40.33**.
- The dataset records more than **136 million** total audience votes.
- **Spider-Man: No Way Home** has the **highest popularity** among the analyzed movies.
- Movie releases show significant variation across different years.
- Rating and popularity vary across different rating categories and genres.
